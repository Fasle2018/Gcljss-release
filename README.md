## 系统要求

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10 及以上（安装包强制 64 位） |
| Excel | Microsoft Excel 2010 及以上（32 位或 64 位） |
| AutoCAD | AutoCAD 2012 - 2025（64 位） |
| .NET Framework | .NET Framework 4.8 或更高（AutoCAD 2025 插件依赖 .NET 8，由 CAD 自带） |

## 安装方法

1. 下载 `Gcljss_Setup_<版本>.exe`。
2. 运行安装程序（安装到 `%ProgramFiles%\工程量计算书`，自动创建桌面/开始菜单快捷方式）。
3. 安装完成后双击桌面快捷方式"工程量计算书"启动，程序会自动注册 Excel 与 AutoCAD 插件。
4. 首次使用在 Excel 中允许加载 VSTO 插件；在 AutoCAD 中输入命令加载插件。

## 更新

- 程序内置「检查更新」功能：Excel 功能区的「检查更新」按钮 → 自动从本仓库 `releases/latest` 拉取新版并下载安装。
- 安装包支持**覆盖安装**：新版本号 > 当前版本即可升级；重复安装同一版本会自动卸载旧版再安装，无文件/注册表残留。

## 版本历史（近期）

### 3.0.28.0（当前最新）
- **反查高亮（呼吸灯）效果升级**：在原有颜色轮转基础上叠加「明暗呼吸 + 线宽脉动」，最亮时线条最粗，定位对象比以往醒目得多；动画相位改按真实时间推进，刷新率抖动不再影响节奏快慢。
- **呼吸效果可按个人喜好调节**：AutoCAD 选项 →「工程量计算书」→「动态显示」新增 5 项参数 —— 色相周期、呼吸周期、亮度下限、呼吸陡度、线宽脉动，每项都有详细说明与取值范围校验（超范围会提示并回退默认值）。「刷新间隔」职责同步收敛为只控制画面流畅度与性能开销，颜色与明暗的快慢改由色相周期／呼吸周期决定。
- **FX 反查任务窗格重构**：改用 GridView 按列分组展示，检索性能优化，切换文档时自动清空，避免残留旧结果。
- **修复三项使用问题**：打开空白 Excel 窗口时「升级批注」按钮正确置灰；低版本文件升级后清理旧版遗留的条件格式（阅读模式现由光带实现）；提前注册中文语言资源，改善首次启动界面显示英文的问题。
- **修复选项面板属性值始终显示粗体**：默认值判定因类型不匹配（Double 属性配整数默认值）恒被判为「已修改」，现已修正；恢复默认后各项恢复常规字体。
- **统一各处默认值**：线宽 20、面积容差 10、提取标记与匹配后转换对象默认开启、文本颜色 LimeGreen —— 首次安装、恢复默认、面板显示三者完全一致。
- **健壮性增强**：动态显示参数在读取入口做范围钳制，配置文件损坏或被手改越界时自动净化并回退默认值；弧形段绘制增加 NaN 防护，避免病态图元导致绘制异常。
- 追溯基准提交：`19f5317`（本次发布对应的最新提交；**下次发布请以 `git log 19f5317..HEAD` 为基准编写升级说明**）。

### 3.0.27.0（近期）
- **批注存储升级为压缩格式**：批注内容按压缩编码存储，大幅减少文件体积；批注编码升级状态常量补充说明，手动升级已是新版时弹提示（不再重复操作）。
- **修复检查更新并发崩溃**：连续点击「检查更新」会并发执行导致多个弹窗/重复下载任务/崩溃，新增防重入标志拦截。
- **修复表达式计算 BUG**：含 Excel 名称/中文字母的表达式改用名称集合替换后求值，摆脱 `Application.Evaluate` 参数上限 255 字符的限制（超长表达式此前会报错）。
- **表达式健壮性增强**：`CleanInput` 修复不支持嵌套备注导致报错的问题；强化为强制括号成对校验。
- **批注写入精确阻断**：QC 清除关联不再破坏对象显示；CC/TQ 命令接入批注写入容量精确阻断（复用 CommentCodec 剩余容量）。
- **「建工计算器」角钢规格表**：删除等边角钢、不等边角钢的冗余型号字段（名称统一由 Name 承载）。
