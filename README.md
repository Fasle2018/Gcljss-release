## 系统要求

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10 及以上（安装包强制 64 位） |
| Excel | Microsoft Excel 2010 及以上（32 位或 64 位） |
| AutoCAD | AutoCAD 2012 - 2025（64 位） |
| .NET Framework | .NET Framework 4.8 或更高（AutoCAD 2025 插件依赖 .NET 8，由 CAD 自带） |

## 安装方法

1. 下载 `Gcljss_Setup_<版本>.exe`。
2. 运行安装程序（安装到 `%ProgramFiles%\工程量计算书`，自动创建桌面/开始菜单快捷方式）。
3. 安装完成后双击桌面快捷方式"工程量计算书"启动，程序会自动注册 Excel 与 AutoCAD 插件。
4. 首次使用在 Excel 中允许加载 VSTO 插件；在 AutoCAD 中输入命令加载插件。

## 版本历史（近期）

### 3.0.69.0（当前最新）

- **修复快速检索小按钮压住「查找」窗口（本版核心）**：小按钮与查找窗口都是置顶窗口，同一层级内的先后顺序由"谁最近显示"决定，因此小按钮每次重新显示都会盖住查找窗口。本版改为**显式指定顺序**，把小按钮排到查找窗口**之下** —— 面板照常显示（保留原有"允许穿透以便同屏比对"的效果），但不再遮挡查找窗口。
  - 按 Windows 官方规则加了三重防护：目标窗口不是置顶时**跳过定序**、定序后**回读自身置顶状态**并在丢失时立即复位、失败路径写测试日志。这是为了避免"为修遮挡反而让小按钮失去置顶、被 Excel 硬件加速的网格盖住而整体看不见"这一更严重的后果。
  - 定序动作紧跟在显示之后执行，切换单元格时不再有瞬时遮挡。
- **修复 64 位下窗口归属失效**：设置宿主窗口归属时误用了 32 位 API，64 位进程下句柄被截断，导致"Excel 最小化时小按钮随之隐藏"实际未真正生效。改为按进程位数分别调用。
- **Excel 弹出模态对话框时不再被小按钮盖住**：对话框打开期间隐藏面板，关闭后自动恢复。
- **切换到其它程序时小按钮立即消失**（原来最多延迟 150ms）：新增窗口失焦事件即时隐藏，原 150ms 轮询保留作兜底。
- **点进搜索框输入时面板不再被误隐藏**：面板自身处于前台时豁免失焦隐藏，输入不被中断。
- **切换工作表/窗口时的状态清理更可靠**：修复一处状态标志被可见性判断吞掉、可能把上一张工作表的候选数据带到新工作表的问题。
- 版本号全项目统一 3.0.69.0。

> 已知边界：在"查找窗口 + 同屏比对"场景下，**点进搜索框输入后**再切换到其它程序时，面板隐藏仍可能残留极短延迟（≤150ms，由轮询兜底）；未点进搜索框时直接切换为即时隐藏。

### 3.0.68.0（近期）

- **新增连续量取命令 CCX（AutoCAD 插件，本版核心）**：命令期间只画线、不写 Excel，**结束时一次性写入**活动单元格，因此 CAD 侧的全部操作都可逆。支持：
  - **单键免回车**：画线中按 `T` 直接进入挑拣、挑拣中按 `B` 直接返回画线，无需再按回车；
  - **挑拣复用**：点选即加入、再点一次移出；被移出的「本次新建线段」在完成时自动从图中删除。启动命令前已选中的对象自动计入；
  - **集合高亮**：所有将计入的对象以流光效果实时高亮（与「对象反查」同一套效果，画线过程中连续流动不闪烁）；
  - **立管点计入**：立管点按其数值计入，并与其他对象一样建立批注关联。
- **新增通用单键捕获能力**：`GL` / `GLS` 的「选择参考图元」提示支持按 `M` 直接进入多参考图元选择，无需回车（原有的 `M` + 回车方式保留）。
- **`TQ` 支持多参照对象**：新增 `M` 关键字，可一次选择多个参照对象，**任一参照匹配即纳入结果**（原仅支持单一参照）。为保护数据安全，位于锁定图层的对象不可作为参照。
- **CCX 稳定性与体验加固**：修复键盘钩子在异常路径下可能残留（会导致整个 CAD 会话吞键）的问题；`Ctrl` / `Alt` 组合键不再被误吞；切换到 Excel 等其它程序时不再误吞按键；集合高亮改为增量刷新（更跟手）；写入前检测 Excel 是否可用、单元格超长或对象已失效时**整批不写并提示**，避免留下脏状态。
- **界面**：「量取」与「连续测量」在功能区合并为一个命令组合，连续测量使用专用图标（明/暗配色下均正常显示）。
- **命令行输出精简**：CCX 过程中只显示命令动作与关键字提示，结束时只输出写入的字符串。
- 版本号全项目统一 3.0.68.0。

### 3.0.67.0（近期）

**3.0.67.0** · 建工计算器（独立计算程序）功能更新
- **新增「四则混合运算计算器」（本版核心）**：建工计算器左侧导航第一项即为计算器 —— 逐行输入算式按 **回车** 即出结果，结果自动插到下一行，可连续往下算；支持括号、用 `{…}` 或 `[…]` 写备注（备注不参与计算）、输入 `cls` 回车清空。选项集中在功能区新增的「计算器」页：**小数位数**（0~10）、**保存内容**（关闭后记住算式，下次启动恢复）、**自动复制**（结果自动进剪贴板）、**字体设置**、**清空**。以后做临时四则运算**不用再另开 Excel 或计算器窗口**。
- **修复：钢板/扁钢等型钢的理论重量可能整体偏小 10 倍（重要）** —— 根因是"钢材密度"这一项设置的历史默认值被写成了 **0.7851**（正确值应为 **7.85 g/cm³**），旧版本还会把这个错误默认值写进用户配置文件、此后每次启动一直沿用。本版修正默认值，并让程序在读取配置时**自愈**：发现密度不在合理区间（6.0~9.5）即按 7.85 处理并回写。**老用户升级后自动恢复正常，无需手工删除配置**。若你此前遇到"钢板/扁钢重量比实际小 10 倍"，升级本版即可解决。
- **型钢计算补全镀锌件**：圆钢、方钢、扁钢、钢板、六角钢、等边/不等边角钢、工字钢、轻型工字钢、槽钢、轻型槽钢共 **11 个页面**全部增加**镀锌件理论重量**与**镀锌单价**；配套新增「**镀锌型钢重量附加系数**」设置（默认 6%，即按镀锌层重量另加 6%），可在功能区「设置」中调整，改后全部页面自动重算。
- **结果显示口径调整**：所有计算结果**内部按全精度参与计算**，界面显示保留 2 位小数（**防腐保温**一组因绝热工程量数值很小，统一保留 **4 位**，避免整列显示 0.00）；「导出 Excel」写入的仍是全精度数值并带显示格式，导出后可继续精确计算。
- **取数更方便**：计算表格中的**只读计算项双击即复制**该单元格显示值到剪贴板（可编辑列不受影响，双击仍是正常编辑），复制结果在**窗口底部状态栏**给出提示。
- **设置项更安全**：钢材密度限定 6.0~9.5、镀锌附加系数上限 100，非法值会被忽略并恢复合理值；设置改为**原子写入**（先写临时文件再替换），避免异常中断损坏配置文件。
- **基础数据修正**（依据规范复核）：焊接钢管 DN150 理论重量 18.81 → **18.18** kg/m；非标焊接钢管 508×5.5 67.16 → **68.15** kg/m；热轧槽钢 [27b 35.823 → **35.077** kg/m。
- Excel 插件与 AutoCAD 插件本版**无功能变更**（仅随版本号同步重新编译）。
- 版本号全项目统一 3.0.67.0。

- **内部加固（不可见）**：瞬态注册失败的留痕与处理、关闭动态显示/卸载插件时的高亮清理更彻底、文字样式与字高异常会写诊断日志。

### 3.0.65.0（近期）

**3.0.65.0**
- **修复：装了新版，Excel 却仍运行旧版加载项（本版核心）**。注册表里的加载项清单此前写成裸路径，VSTO 会先把加载项复制进 ClickOnce 缓存，此后**长期从缓存加载**，缓存一旦存在就不再回安装目录取新版 —— 实测安装目录已升到 3.0.64.0，Excel 进程内实际加载的仍是缓存里的 3.0.62.0，表现为「升级后软件行为毫无变化」。现改为微软标准写法 `file:///<路径>|vstolocal`（就地加载、不使用缓存），**以后升级即刻生效、无需再清缓存**；安装/卸载程序对清单路径的解析同步统一。
- **改进：插件关闭时主动释放 Excel 对象引用**。此前 `Application` / `Workbook` / `ListObject` 三个引用只赋值不释放，回收被推迟到卸载阶段，可能让 Excel 多等一次 60 秒级超时；现改为关闭时主动断开，实测该步耗时 11 毫秒、整个关闭清理 22 毫秒。
- **新增：关闭过程毫秒级诊断留痕**（启动进程号、工作簿关闭时刻、各清理步耗时、总耗时），正式版同样有效，便于日后快速区分「插件慢」与「外部因素」。
- **说明**：本版同时实测确认「关闭 Excel 后 EXCEL.EXE 驻留 30~60 秒」与本程序无关 —— 干净环境、安全模式（反而更慢）、Word 对照均能复现，根因是本机到 Microsoft 服务的 TCP 建连约需 10 秒，Office 关闭时的联网请求收尾被放大；完整排查过程见主仓库 `DOC/排障-Excel关闭后进程驻留-2026-09-21.md`。
- 版本号全项目统一 3.0.65.0。

### 3.0.61.0（近期）

**3.0.61.0**
- **修复：快捷键反查 CAD 偶发弹出「错误:异常来自 HRESULT:0x800AC472」（本版核心）**。根因是 Excel 在用户界面操作进行中（例如鼠标按住左键拖拽选区尚未松手、或在编辑栏输入公式）会临时挂起对象模型，此时读取单元格批注会被拒绝（该错误码即 Excel 的 VBA_E_IGNORE）；按 Ctrl+R 时若手指仍在拖拽，恰好命中这个极短的时间窗 —— 这也解释了为什么只有快捷键入口偶发（右键菜单与功能按钮的点击动作必然先结束手势）。
- **修复方式：选区批注改为「非阻塞延后读取」**。优先立即读取（空闲场景与以往完全一致、零延迟）；若恰好被挂起，则交回界面消息循环、每 120 毫秒重试一次，**等你松手后自动完成反查**，全程不冻结界面（上限 15 秒，超时改为气泡提示）。**不再弹出红色错误框**。
- **附**：获取 AutoCAD 实例在宿主忙时不再原地等待重试（此前那种等待方式会阻塞界面），改为记录日志并给出可操作提示。
- **内部优化**：清理了 109 处只在调试构建生效、发布包中完全无效的调试输出语句，并删除零引用的调试辅助类；关键失败路径统一改用发布版同样有效的文件日志（`%TEMP%\工程量计算书\TestLog\`）。
- 版本号全项目统一 3.0.61.0。

### 3.0.60.0（近期）

**3.0.60.0**
- **反查瞬态高亮新增「流光」效果（本版核心）**：颜色沿对象长度流动的渐变，与 CC 画线特效同源。设置面板「动态显示」三选：无 / 呼吸 / 流光；选「流光」时自动隐藏只对呼吸生效的子选项，避免"改了没效果"的误导。
- **新增「流光细腻度」设置**（动态显示 → 流光细腻度）：四档 —— 高(每段8像素) / **标准(每段12像素，默认)** / 低(16像素) / 最低(20像素)。档位越高色带越窄越细腻、绘制量越大；默认"标准"覆盖绝大多数场景（反查对象在一百个以内时绰绰有余）。
- **流光性能优化**：新增"按对象屏幕长度取段数"的口径（效果不再随反查对象变多而下降），配合几何属性缓存，实测 916 个对象的场景帧内耗时由约 23ms 降至约 12ms，鼠标操作流畅。
- **自动档位降级（性能兜底）**：反查对象很多、当前档位跑不动时，先按实测帧率**自动降到更低的档位**继续维持流光；连"最低"档都不流畅才回退为**呼吸**效果。降级只在本会话内生效、**不改动设置**，重启 CAD 即可重新尝试。命令行只给一句提示，详细过程写入日志。

### 3.0.56.0（近期）

**3.0.56.0**
- **修复升级链路：校验失败后「待安装数据」被后台任务重新写回（本版核心）**。现象：主程序启动时已提示「更新包校验未通过，已放弃本次升级」，但注册表 `Update_*` 数据仍残留，且每次启动重复提示。根因：下载任务的 SHA256 校验（约 68 MB 安装包）在部分机器上耗时可达数十秒，用户在主程序中放弃升级并清除数据**之后**，后台任务才完成并写回 → 数据「复活」。现引入「清除优先」语义：当清除时刻晚于本轮任务开始时刻时，后台任务不再写回；正常升级流程行为不变。
- **升级链路补齐成功路径日志**：`Clear()` 此前仅在失败/残留时留痕，成功时完全静默，无法与「根本没被调用」区分；现成功清除与「跳过写回」均有日志，便于现场定位。
- **收紧本地包复用判定**：仅当远端提供 SHA256 **且**本地文件哈希匹配时才复用，取消「无哈希时按文件非空复用」的退化分支（避免本地缓存损坏被静默接受）；复用分支补一次进度回调，修复更新窗口停留在 0% 的问题。
- **批注 XML（XXE 防护）失败路径兜底**：解析含 DTD / 外部实体的批注 XML 时捕获异常、落盘留痕并返回空，不再让异常逸出到 CAD 命令。
- **变量表**：内置名称与工作表级名称在界面上标注为只读（这些名称保存时本就原样保留），避免用户编辑后被无声丢弃；跳过重建时写日志。
- **CAD 反查**：区分「读取 CAD 状态失败」与「确实没有打开图纸」，不再把前者误报为后者；失败改为落盘日志（此前仅调试输出，发布版无痕）。
